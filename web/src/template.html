Installing

    
    
      
  1. Format a USB stick as FAT32 (MBR partition table).
    2. 
      
  2. Create a folder named iLX-W650 in its root and put the downloaded Alpine_SYSTEM.FIR inside it — nothing else
          (no micom.srec, tw8_*.bin or Alpine_BT.dfu).
    3. 
      
  3. On the head unit, run Firmware Upgrade and keep power stable until it finishes and restarts.
    4. 
      
  4. Keep your original Alpine_SYSTEM.FIR: flashing it the same way restores stock (there is no version check).
    5. 
    

    
Unofficial modification — use at your own risk. The page checks the firmware build, rebuilds the archive and
      footer checksum, and decompresses its own output to confirm it matches before offering the download. The boot loader,
      recovery and pre_main are never changed. If the patched main firmware ever failed to start, the unit could only
      be restored by reprogramming its serial flash chip, so keep an SPI programmer in mind.
